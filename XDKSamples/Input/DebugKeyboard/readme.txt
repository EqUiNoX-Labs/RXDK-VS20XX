Description
===========
   Shows how to use a keyboard for debug builds of a game.


Required files and media
========================
   Copy the media tree to the target machine before running this sample.


Programming Notes
=================
   The Xbox debug libraries include keyboard support which may be extremely
   useful to games under development. The most common usage would be to interact
   with a console-like envrionment to control various development options in the
   game. The keyboard is only intended for this usage, and not for gameplay or
   user-input in any way. The keyboard is not supported in release versions of
   the Xbox libraries.
