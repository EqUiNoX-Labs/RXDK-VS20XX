Description
===========
   The Lightgun sample shows how to use a lightgun in an Xbox game.
  

Required files and media
========================
   Copy the media tree to the target machine before running this sample.


Programming Notes
=================
   Some important concepts to using lightguns on the Xbox include calibration
   of the gun, a white flash lasting for one field, and handling different
   display modes. See the sample and the documention for more specifics on
   using lightguns.
