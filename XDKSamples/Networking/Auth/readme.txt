Description
===========
   This sample illustrates Xbox Online account enumeration, PIN entry,
   PIN validation, sign on and authentication. The sample shows proper online
   multitasking using XOnlineTaskContinue(), as well as error handling
   for PIN and sign on failure.


Programming Notes
=================
   The sample utilizes multiple state machines for allowing up to four users
   select accounts for sign on.
