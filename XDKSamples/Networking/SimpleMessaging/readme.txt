Description
===========
   The SimpleMessaging sample demonstrates how to use the new unified messaging
   APIs to create, send, and receive messages.  Friend invites can be received 
   this way, or processed using the traditional APIs (XOnlineFriend functions).        
      

Programming Notes
=================
    Full technical information on these APIs is available in the SDK help under 
    XOnlineMessage<api>
