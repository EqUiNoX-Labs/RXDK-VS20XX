Description
===========
   The SimpleTeams sample demonstrates how to use the basic team APIs to create 
   a team, recruit members, view members and teams, kick members out of the team, 
   and delete teams.  A game will also want to use the message APIs to receive 
   and process team messages (see SimpleMessaging).   The presence APIs are also 
   used here to show the current online status of teammates.

Programming Notes
=================
    Full technical information on these APIs is available in the SDK help under 
    XOnlineTeams<api>
