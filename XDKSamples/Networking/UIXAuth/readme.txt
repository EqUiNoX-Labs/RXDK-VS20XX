Description
===========
   The UIXAuth sample shows how to implement Live Authentication using the
   UIX library to handle most of the work.


Required files and media
========================
   Run copytoxb.bat to copy the required fonts and skin files to the Xbox prior
   to running this sample.


Programming Notes
=================

   UIXAuth is designed to be a simple demonstration of how to implement Xbox
   Live Authentication using the UIX engine.  With the June release, UIX
   supports two and four player authentication.
