Description
===========
   The SimpleFriends sample demonstrates the XOnlineFriends APIs.  In order
   to run the sample, you should have two accounts on your Xbox, and a Output
   viewer like Visual Studio.NET or xbwatson running.
   
   Because no session is actually created, the game invitation APIs are not
   implemented, but they are described fully with examples in the source code.
   (Search for "Game invitations")
