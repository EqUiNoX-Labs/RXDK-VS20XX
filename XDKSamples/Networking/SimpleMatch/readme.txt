Description
===========
   The SimpleMatch sample demonstrates the Xbox Live Matchmaking API.

Programming Notes
=================

The MatchSim tool is used to create queries which are then submitted
to XBox Developer Support.  The SimpleMatch.xms file was used to generate
the query used by the SimpleMatch sample.
