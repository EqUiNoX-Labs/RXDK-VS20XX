Description
===========
    The primary purpose of this sample is to show an example of writing a
    custom UIX feature. In this example, we have wrapped the functionality
    of the "Virtual Keyboard" sample as a UIX feature.
    
Required files and media
========================
   Copy the media tree to the target machine before running this sample.


Programming Notes
=================
    UIX has extensibility features that allow a developer to write custom UIX
    features. The value add for writing custom UIX features is to minimize the
    amount of extra UI code that needs to be written. Within UIX, a feature
    can load skinnable objects and have convenient access to localized text 
    strings.

	For more comprehensive programming notes, please read the file header
	comments for each of the source files in the project.
