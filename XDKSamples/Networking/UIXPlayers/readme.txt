Description
===========
   The UIXPlayers sample shows how to implement a players list using the
   UIX library to handle most of the work.
   The players list is used to create a lobby and various other types of
   players lists.


Required files and media
========================
   Run copytoxb.bat to copy the required fonts and skin files to the Xbox prior
   to running this sample.


Programming Notes
=================

   This sample is integrated with XHV to demonstrate detecting when somebody is
   talking and highlighting them.
