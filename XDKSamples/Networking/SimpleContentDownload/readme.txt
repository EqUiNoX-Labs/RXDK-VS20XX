Description
===========
   The SimpleContentDownload sample shows how to enumerate and download content
   from the Xbox Live services.
   

Required files and media
========================
   Copy the media tree to the target machine before running this sample.


Programming Notes
=================
   The sample uses the XOnlineOfferingEnumerate() and XOnlineContentInstall()
   functions to enumerate and download content. The sample also shows how to
   pump the related online tasks, show progress, and detect errors from the Live
   service.
