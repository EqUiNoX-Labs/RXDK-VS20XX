Description
===========
   The SimpleUnitStats sample demonstrates the XOnlineStats Unit APIs. 
   A "unit" is a dynamic team consisting of up to four players.

   In order to run the sample you will need to have an Output
   viewer like Visual Studio.NET or xbwatson running. Since a Unit must have
   two or more members, aleast two valid accounts sounds be present either
   on the hard-drive or on a memory unit inserted into a controller.
