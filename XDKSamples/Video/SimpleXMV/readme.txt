Description
===========
   The SimpleXMV sample shows how to play an XMV movie file in the simplest way
   possible. For more sophisticated and powerful variations on playing XMV
   files, see the XMVPlayer sample.
   

Required files and media
========================
   Copy the media tree to the target machine before running this sample.
