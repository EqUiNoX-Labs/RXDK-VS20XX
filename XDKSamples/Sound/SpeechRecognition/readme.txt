Description
===========
   The SpeechRecognition sample demonstrates how to use the speech recognition
functionality of the new Xbox High-Level Voice library (xhv.lib).  Although
XHV also supports voice chat, this sample is using it for voice recognition
only.  The SimpleVoice sample demonstrates how to use the voice chat 
functionality of XHV, and a future sample will demonstrate how to use both
features together.
   

Required files and media
========================
   Copy the media tree to the target machine before running this sample.


Programming Notes
=================
   The sample reads in the .txt files used to generate the speech recognition
banks in order to display recognized words on screen.  The parsing of these
.txt files is for illustrative purposes only.
