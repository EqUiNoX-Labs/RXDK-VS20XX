Description
===========
   This is a simple app to play some sounds using DirectMusic.


Required files and media
========================
   Copy the media tree to the target machine before running this sample.


Programming Notes
=================
   The code loads and plays sounds using the follow DirectMusic interfaces:
	IDirectMusicLoader8
	IDirectMusicPerformance8
	IDirectMusicSegment8
	IDirectMusicAudioPath8
   Since DirectMusic does most of the work, the sample is very simple.
