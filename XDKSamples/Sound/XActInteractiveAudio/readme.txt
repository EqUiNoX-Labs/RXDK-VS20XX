Description
===========
   The XActInteractiveAudio sample demonstrates how to play back and control
interactive audio using the XACT runtime engine.  The XACT project contains
just one sound cue, which is an interactive audio cue.  The cue responds to
changes in a global XACT variable by transitioning between different sounds.
   

Required files and media
========================
   Copy the media tree to the target machine before running this sample.
