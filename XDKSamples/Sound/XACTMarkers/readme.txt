Description
===========
   The XACTMarkers sample demonstrates how to use XACT markers and
   notifications. This samples used markers placed in content, by the content
   creator, in the wave file, on each word. The markers are then detected by
   the sample through the use of notifications, and the word corresponding to 
   the spoken word from the wave file is then shown on the screen.
   

Required files and media
========================
   Copy the media tree to the target machine before running this sample.
