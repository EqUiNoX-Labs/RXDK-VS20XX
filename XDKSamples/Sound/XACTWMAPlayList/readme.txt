Description
===========
   The XActWMAPlayList sample demonstrates how to use the XACT library to manage
   both game provided and user created soundtracks.  This sample can easily be
   ported for use in your own game, with a few restrictions.  Game provided
   soundtracks must be sets of WMA files in their own directories (no other
   file types allowed).
   
   As is shown in the sample, it is recommended to reserve one cue in an XACT
   soundbank to use to manage soundtracks.  This makes things simple and keeps
   programmers and sound designers mixing up with soundbanks are for what purpose.
   

Required files and media
========================
   Copy the media tree to the target machine before running this sample.
