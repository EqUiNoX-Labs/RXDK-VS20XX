Description
===========
    Shows the methods for getting the WMA soundtracks, displaying the list
    and playing selections from the list.  The playback object (CWmaFileStream)
    is taken from the wmastream sample (with some minor modifications).


Required files and media
========================
   Copy the media tree to the target machine before running this sample.
