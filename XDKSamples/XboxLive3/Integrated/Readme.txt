Description
===========

   The Tsunami Integrated Sample demonstrates a variety of features previously 
   available in other Tsunami samples; such as team management, matchmaking, 
   and storage. The sample also contains features not available in previous samples, 
   such as team competition management and voice mail.

Title Notes
===========

   This sample uses a "Leaderboard" posted to PartnerNet. A new leaderboard will have 
   to be created for your title ID. Leaderboards are created and submitted to 
   PartnerNet using the Xbox Live Authoring and Submission Tool (aka XLAST).
   If you have questions about the Leaderboard creation process please contact your 
   Xbox account manager.

   This project uses multiple XQS files generated by the XLAST tool. One of these files
   has been modified by hand to return an extra result. If you autogenerate the 
   COMPS.XQS file from COMPS.XLAST this patch will have to be reapplied. Both of these
   XQS files may co-exist on PartnerNet and may be submitted separately.

XQS Patch Notes
===============

   To apply this patch search
   for the line:
   <dataset id="2" quota="-1" name="SE entrants" typeid="0">
   Add the following line to the end of the "schema" section:
   <attribute name="att_comp_name" hexid="0x8011000E" kind="string" maxlen="32" default="" />
   Next search for the line
   <query hexid="0x1" op="search" name="My Competitions">
   In the "Returns" section add
   <return name="att_comp_name" hexid="0x8011000E"/>
   as the last line in the section.

   The COMPS.H file was also hand patched to add this data ID as a constant.

   Before "building" COMPS.XQS backup the following files to assist in re-applying 
   the patch:
   
   COMPS.XQS
   COMPS.H
   COMPS.CPP

Programming Notes
=================

   This sample contains the following implementation files:

   common.cpp          - Contains basic functions to aid in rendering and completing 
                         Xbox Live tasks.

   comps.cpp           - Contains internal data for use in competition feature.

   GameSession.cpp     - Contains code used to manage game sessions/matches.

   IntegratedDemo.cpp  - Contains code that manages overall UI/flow of the sample.

   match.cpp           - Contains matchmaking object architecture.

   Menus.cpp           - Contains basic functions to aid in menu operations in the 
                         sample.

   Teams.cpp           - Contains code used to manage teams.

   tourney.cpp         - Contains code used to manage tournaments.

   UserContent.cpp     - Contains code for a user content object used to demonstrate 
                         Xbox Live storage functionality.

   UserSettings.cpp    - Contains code used to stored user settings on the network
                         using the Xbox Live Storage service.

   XHVVoiceManager.cpp - Contains voice mail sending architecture.

Running the Sample
==================
   
   If you are running this sample to play a competition and perform matchmaking, two 
   Xboxes and a personal computer with the Matchmaking Simulation tool installed are 
   required. For setup purposes:
   
   * If you haven't already done so, please upload your Matchmaking simulation file
     (Matchmaking.xms) as a PartnerNet Change Request via the following link:

     https://xds.xbox.com/BPProgInfo.asp?Page=/scripts/psUpload/Upload.asp#

     Note: you need only do this once.

   * First open the provided MatchMaking simulation file with the MatchMaking 
     Simulation Tool.
   
   * Copy the Integrated Sample XBE to each Xbox.
   
   * Using the Xbox Neighborhood tool, set one Xbox as the default box. Then using the 
     MatchMaking Simulation Tool, choose TOOLS->CONNECT XBOX to route the Xbox's 
     QuickSearch through your computer.
   
   * Repeat the previous step for your second Xbox.

   In other cases, one Xbox is required to run this sample. At least one Xbox Live 
   account is also required to run part of this demo. Having multiple Xbox Live 
   accounts is highly recommended, in order to form teams.

   NOTE: Tournament rounds are only played via the Join Round option when viewing the
   topography of a competition your logged-in team/user is viewing.  Using Create Match
   and Quickmatch on the Main Menu for a user login will have *no* effects on the 
   tournament results involving the players in the match.
