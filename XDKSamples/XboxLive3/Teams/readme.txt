Description
===========

   The Teams Sample demonstrates how to create and manage teams as well
   as maintain statistics and leaderboard for those teams.


Programming Notes
=================

   This sample is contained by only one implementation file:

   TeamsDemo.cpp - Contains the main logic to demonstrate team managment and statistics.


Running the Sample
==================

   Only one Xbox is required to run this sample. At least one Xbox Live account is
   also required for this demo. Having multiple Xbox Live accounts is a positive.
   
   Simply compile and run the sample.

   You may use the provided XLAST file as a template to create new leaderboard for
   your specific title. Please remember to change the TitleID to your title's ID number.
