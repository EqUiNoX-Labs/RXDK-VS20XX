Description
===========
   The PushBuffer sample illustrates using static pushbuffers. Pushbuffers can
   be thought of as display lists or instruction buffers to the GPU. Rather
   than rendering a scene via a myriad of D3D calls each frame, the calls can
   be recorded into a static pushpuffer. Any dynamic data within a pushbuffer,
   such as vertex shader constants that control the rotation of an object, can
   be modified on the fly via "fixup" objects.

   Writing the pushbuffer data out on the PC and then loading it on the Xbox
   is also demonstrated.


Required files and media
========================
   Copy the media tree to the target machine before running this sample.
   media\PushBuffer.dat is generated by CreatePushBufferOnPC project.


Programming Notes
=================
   The pushbuffer used in this app simply draws two rotating triangles; one
   using DrawPrimUP with a vertex shader and the other using a vertex buffer
   with the fixed-function pipeline. The triangles are rotated via matrices and
   vertex shader constants that are updated per-frame with push buffer "fixup"
   objects.
