Description
===========
   This sample is the same as the XACTCuePlayback sample. Take a look at the 
   readme file for a description of the sample functionality.

   This sample demonstrates the use of custom allocators. At the time of writing
   this sample, only the XACT lib is enable with this functionality. This is why
   an XACT sample was chosen for this sample. Eventually all Xbox libs will have 
   this functionality. 

   A new file is added to the sample called memalloc.c. This is where the custom
   allocator is defined for this sample. 

Required files and media
========================
   Copy the media tree to the target machine before running this sample.
